## 1. Unlink
**Dotation totale :** $5,000  
**Site :** [unlink.xyz](https://unlink.xyz) | **Twitter :** [@unlink_xyz](https://twitter.com/unlink_xyz)

> Unlink est un SDK de 5 lignes permettant de construire des applications privées sur n'importe quelle blockchain publique. Envoyez, recevez et utilisez la DeFi de manière totalement privée on-chain.

### 💰 Prix Unlink
* **Best Private Application — $3,000**
    * *Objectif :* Créer une application grand public (Consumer-facing) pour gérer des paiements privés sur des chaînes EVM publiques.
    * *Exemples :* Paie privée, transferts P2P, checkout marchand, abonnements. L'accent est mis sur une UX aussi simple que Venmo ou Revolut.
* **Most Creative Privacy Use Case — $1,000**
    * *Objectif :* Utilisation originale et inattendue du SDK au-delà des simples paiements. Priorité à l'originalité et à la pertinence réelle.
* **Best Private DeFi Integration — $1,000**
    * *Objectif :* Ajouter de la confidentialité à une action DeFi (Swap, lend, yield) sans exposer l'activité du wallet.

### 🛠 Critères de qualification
- Utilisation obligatoire du package npm `@unlink/sdk`.
- Demo fonctionnelle sur **Base Sepolia** avec au moins une transaction privée réussie.
- Repo GitHub public avec un README clair.
- Vidéo de démo (max 3 min).

## 3. Chainlink
**Dotation totale :** $7,000  
**Site :** [chain.link](https://chain.link) | **Twitter :** [@chainlink](https://twitter.com/chainlink)

> Le standard de l'industrie des réseaux d'oracles pour alimenter des applications avec un minimum de confiance.

### 💰 Prix Chainlink
* **🔗 Best Workflow with Chainlink CRE — $4,000**
    * *(2 équipes gagnantes de $2,000)*
    * *Objectif :* Utiliser le **Chainlink Runtime Environment (CRE)** pour orchestrer de la logique on-chain et off-chain. Connecter des blockchains à des APIs, des LLMs ou des systèmes d'entreprise.
* **🔒 Best usage of Chainlink Privacy Standard — $2,000**
    * *(2 équipes gagnantes de $1,000)*
    * *Objectif :* Utiliser **Confidential Compute** ou **Confidential HTTP** pour protéger les secrets (API keys), les données d'entrée/sortie et les flux de valeurs.
* **🌎 Connect the World with Chainlink — $1,000**
    * *Objectif :* Utilisation générale des services Chainlink (CCIP, Price Feeds, Data Streams, PoR, VRF).
    * *Note :* Utilisez le CRE à la place de Functions ou Automation (ces derniers seront bientôt obsolètes).

### 🛠 Critères de qualification
- Le service Chainlink doit provoquer un **changement d'état** sur la blockchain (la simple lecture de flux de données en front-end ne suffit pas).
- Pour le prix CRE : Simulation réussie via la CLI ou déploiement live.
- Bonus pour l'utilisation combinée de plusieurs services Chainlink.
